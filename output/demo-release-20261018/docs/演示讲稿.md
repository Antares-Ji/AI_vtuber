# 90秒 Demo 讲稿

0—15秒：这是姬岁歌AI虚拟主播工程的游戏控制阶段展示。目前有一个已验收的轻量游戏AI，以及一个开发中的Minecraft原型。

15—45秒：展示Flappy Bird窗口。使用游戏附带的预训练Dueling DQN与碰撞预判保护层，不调用大语言模型。100个独立随机场景均达到1,000分，单局耐久达到10,000分，原始结果在evidence目录。游戏没有最终关卡，因此这里叫“达到验收目标”，不叫通关。

45—70秒：展示Minecraft历史截图与架构。千问负责规划，Mineflayer负责执行，OBS连接到网页。采集、工具制作和部分导航已有局部成功；房屋、床和稳定生存流程未完成，当前任务已停止。

70—90秒：展示攻略MD和问题清单。文档包含明确材料、动作和验收条件；已投递到规划队列但尚未被运行循环消费。后续方向是生存闭环可靠性和服务协同，不把接口开放或文档保存包装为已完成的智能能力。

不要说：全部游戏通关、Minecraft稳定自主生存、75动作全部实机通过、千问已经完成强化学习、Flappy已经与虚拟主播全流程集成。
