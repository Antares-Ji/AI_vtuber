# v5r2 candidate data (not trained)

This review package corrects the synthetic food-history values flagged in v5r1 and three development-only action-set bounds found in Astra's first v5r2 review. It has not been used for training, GPU evaluation, or checkpoint selection. Frozen v5r1 remains unchanged. The 32 synthetic training examples are appended after the unchanged 182-row v4r1 replay; twelve independent examples are development-only and do not overlap normalized prompts with training or the prior 182 rows.

Food changes use local Minecraft 1.21.11 registry values: cooked chicken +6 (7→13), bread +5 (8→13), raw mutton +2 (6→8), and apple +4 (5→9). These are synthetic histories, not claims about observed play. Development action sets respect available materials: four logs permit up to 16 planks; crafting a table and an iron pickaxe are bounded to one output. Raw-rabbit recovery is not included as a training label; current runtime now accepts rabbit in `FOODS`, so earlier executor rejection evidence is stale.

The final training file hash is unchanged from the first v5r2 build. The development file was revised after review: the manifest preserves its initial hash and records the exact three changes. Local semantic preflight and Astra's independent review passed schema, runtime prompt compaction, six-result history consistency, food labels, mining tools/targets, craft/smelt prerequisites, recipe-hint consistency, geometry, durability, replay prefix preservation, prompt overlap, and material-bounded development craft sets. Astra checked 44 selected labels; no final holdout labels or model endpoint/GPU were used. The replay's first 182 rows remain byte-identical.

Using the Qwen tokenizer and inference chat template, train prompts are 1,586–2,112 tokens (31/32 within the 1,800–2,600 live target); development prompts are 1,871–2,097. The longest full train sequence is 2,129 tokens and the longest development sequence is 2,114. A 2,304-token cap preserves every train/dev assistant label. This is only a coverage measurement; no training configuration or checkpoint has been selected.

Data and report hashes are recorded in the manifest.
