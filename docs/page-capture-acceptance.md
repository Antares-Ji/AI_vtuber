# 入口自动采集与纵向拼接

在 `/vision.html` 选择游戏窗口和一个已修正的主界面入口，点击开始自动采集，手动进入入口、向下滚动。每次停留约一秒，结束采集后自动批量对齐。程序不操作游戏。

本轮是保守的纵向滚动 MVP，不是完整页面识别。入口关联由用户选择决定；程序不会证明当前画面确实属于该入口。进入前捕获的主界面、弹窗等可能作为独立画面留下。切换其他入口前应结束本次采集。

## 验收

1. 选择“1 设置”，开始采集，进入设置：状态显示已保存的帧数，连续静止不重复保存。
2. 缓慢向下滚动，每次保留至少约一半重叠并停留一秒：结束后检查长图文字连续、无缺行或重复。
3. 检查固定侧栏和顶部：长图只含滚动内容，完整原图单独保留供参考。
4. 快速跳页、切换标签、反向滚动：允许分成独立结果，不应硬拼接。算法不是语义页面检测，所有长图仍需核验。
5. 上传中结束采集：等待当前上传后再拼接。停止共享会自动结束采集。刷新或关闭页后，可重新打开页面处理上次原图。

最多40张、单图最多1920×1200浏览器缩放，保存 JPEG；每份长图最多2400万像素。小范围动画可能被忽略，大面积动画可能导致一直无法停稳。横向滚动、无重叠滚动及复杂多滚动区不支持可靠拼接；发生不确定时保留独立原图。

保存位置：`runtime/vision/page-sessions/<会话UUID>/`。`manifest.json` 记录 `parentScene=home`、入口ID与名称、帧顺序、拼接裁剪区域与位移。`frame-*.jpg` 是原图；`segment-*.png` 是可人工核验的结果。固定栏坐标仍以原图为准，不可直接使用长图坐标点击游戏。当前尚未自动把长图导入按钮标注编辑器。
