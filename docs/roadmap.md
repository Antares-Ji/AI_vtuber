# 双线程路线图

这个项目以后按“双线程”推进：

```text
工程线：我继续优化 AI 主播
学习线：每次优化都配一节小白源码课
```

## 当前学习定位

你现在的默认基础：

- 刚学完 C++ 语法。
- 能理解变量、函数、条件、数组这些基本概念。
- JavaScript、HTML、CSS、后端、API、TTS、LLM 工程都按新知识处理。
- 课程目标不是考试，而是能逐步看懂并修改这个项目。

## 近期批次

1. 学习资料长期化：课程、术语表、开发日志。
2. DeepSeek / LLM 状态优化：能看见外部模型是否接入。
3. Brain 模块拆分：人格、情绪、记忆、LLM、回复分开讲。
4. 情绪和记忆升级：情绪分数、衰减、三层记忆。
5. TTS 模块化：先浏览器 TTS，再 Edge TTS / GPT-SoVITS / CosyVoice。
6. Live2D 接口预留：你买模型后放进 `public/live2d/`。

## 第 5-14 课路线

- 第 5 课：`fetch` 和 API，前端怎么把弹幕发给后端。
- 第 6 课：JSON 和数据格式，弹幕/回复/记忆为什么都像 `{}`。
- 第 7 课：TTS 和嘴型，文字怎么变成声音，嘴巴怎么跟着动。
- 第 8 课：`server.js` API 路由，后端怎么分辨不同请求。
- 第 9 课：弹幕队列，为什么要排序、去重和冷却。
- 第 10 课：`brain.js` 总览，主播大脑为什么要拆模块。
- 第 11 课：情绪系统，关键词、分数、衰减分别是什么。
- 第 12 课：记忆系统，短期记忆、用户记忆、角色记忆的区别。
- 第 13 课：LLM API，DeepSeek/OpenAI-compatible 是怎么接入的。
- 第 14 课：模块化，为什么大项目不能都写在一个文件里。
