# 0-1 本地落地修复与两遍实测

最终版本连续两遍完成本地选卡、部署、松开、方向确认和落地核验；动作后截图及独立录像均确认角色留在地图上、出现血条，剩余部署数从8变为7。执行中没有Codex逐步发坐标。

## 修复

1. 原程序把绿色部署格交给“按钮定位”提示，提示还要求忽略当前高亮。这与部署区域的定义冲突。新增deploy-tile和deploy-direction空间定位提示，将成功方向框图与当前画面一起交给本地千问。
2. 单靠新提示仍不稳定：中间批次第一次成功，第二次落点偏移且模型误报成功。选人会改变相机视角，不能直接复用原坐标。
3. 增加本地参考图匹配：ORB匹配地图特征，映射经过实测的落点，确认目标像素仍为绿色。与模型提案偏差过大时采用映射位置；没有足够地图匹配或绿色证据就停止。该步骤是本地传统视觉校正，不能称为纯千问定位全部成功。
4. 拖入后用白色菱形边线确认真实方向框；校正方向拖动中心。松开使用此前成功的左键释放路径，再发起独立方向拖动并释放。最终用当前UI部署数与成功/失败参考字形比较，阻止模型误报。

千问、YOLO、参考匹配和控制器均在本机运行。YOLO仍是通用COCO模型，不是已经训练成熟的游戏检测器。本次改进是空间提示、参考图与控制核验，不是新权重训练。
