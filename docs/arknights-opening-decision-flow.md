# 明日方舟开局判断逻辑（用户规则，2026-09-26）

## 1. 战斗地图出现后，第一步先暂停

确认战斗HUD出现，再按Space暂停；截图核验暂停状态。不能在加载画面盲按后假定已暂停。

关卡地图已有节点被选中时，先点击地图内部空白处退出当前选择，再选下一关（用户实测补充）。空白点击仅在地图裁剪区域内识别，不能落到右侧代理指挥或开始按钮；新关卡必须复核标题后才能开始。

从当前截图找到红门（敌方出生点）、蓝门（保护点），建立地面可连通路径。分支、汇合、拐角、障碍和可能漏怪路线分别记录。飞行出生点和飞行路线单独记录，不能套地面连通图；优先准备已确认可对空的高台输出。特殊对空能力以本局干员面板为准。

## 2. 费用驱动的部署顺序

基础顺序：先锋回费 → 主力地面干员 → 高台输出 → 奶位。不是固定三先锋模板。每次检查当前费用、卡片实际费用、敌人接近程度、现有阻挡、对空需求、治疗压力，再决定下一位。无人机临近时提前对空；前线有生存风险时提前治疗。

选中相应干员后查看绿色合法格；灰格不能落地。绿色只证明当前干员可放，不能自动证明路线覆盖合理。地图切换或选中视角变化后不得重放旧坐标。

## 3. 攻击范围和朝向共同决定站位

先读当前范围小图和技能范围变化，再比较候选格、四个朝向对敌人路线的覆盖。记录选择理由。维什戴尔朝下可能覆盖更多路线，但必须根据本关高台和敌人路径验证，不能机械规定每关朝下或朝右。

落地必须同时验证：姓名正确、真实方向框、朝向确认、剩余部署数变化。输入API返回成功不等于部署成功。

## 4. 技能是闭环必需状态

黄色就绪标记是候选线索。选中干员后复核姓名、技能名和READY/技力，使用鼠标技能按钮或E触发；F是倍速，不能当技能键。

回费先锋技能就绪且需要费用时优先开，不能一直憋技能导致后续无法部署。释放前后记录费用、技力、技能状态；持续回费要等待效果窗口验证。输出技能按敌群、精英压力与覆盖释放；不能为消除黄色图标无条件浪费。

释放后复核实际效果：READY消失/技力重置、费用增量或攻击防御等状态变化。技能定位失败必须改进并恢复，不应永久改成只等自然回费。

## 5. 特殊机制备忘

用户提供：陷阱师「望」部署本体后生成棋子；棋子还需单独部署，作为贴地爆炸陷阱，可对地和对空，敌人触发引爆。

此条保存为用户提供的待本局面板/录像验证机制；当前未实际部署「望」，不能标记为已测。后续记录本体/棋子的费用、可放格、触发条件、伤害目标类型和数量限制，再接入自动决策。

## 6. 每轮日志与复盘

每次截图关联唯一证据路径；保存本地千问和YOLO原始输出、OCR、动作前后状态、耗时与结果。区分实战胜负、操作失败和未知状态。失败先归因并记录改变了什么，再恢复同局或重试同关。真实结算确认后才推进。

总结包括红蓝门/空中入口、地面连通与候选飞行路径、地面/高台、干员范围/阻挡/技能、费用时间线、部署朝向、技能就绪到释放耗时、胜负和优化。相似关卡只提供线索，不能替代本关读图。
