# 原神低延迟双 worker 与校验后预执行

用户在 2026-11-02 要求停止 Codex 接管对照测试，先改架构：少解说、关闭思考、限制输出、移动和交互分工，并在当前动作执行时预规划下一步。此指令是本改动的范围；没有恢复实机剧情。

## 已实现

- DeepSeek 剧情默认使用两个逻辑 worker。`movement` 处理移动、转向、追踪与目录传送；`interaction` 处理菜单、F、对话和战斗场景。共享短结构化 handoff 和真实原生回执，不相互生成长篇汇报。
- 默认两路复用当前 DeepSeek 模型。可分别设置 `GENSHIN_MOVEMENT_MODEL`、`GENSHIN_INTERACTION_MODEL`；没有自动更换供应商，也不代表默认使用两种不同底层模型。
- 两路请求均明确 `thinking:{type:'disabled'}`；移动输出上限 256 token，交互 384 token。reason 最多 24 字，commentary 强制为空。前台调用限 20 秒，投机调用限 25 秒，仍受父会话取消控制。
- 默认启用；`GENSHIN_STORY_PIPELINE=legacy` 可恢复原剧情决策流程。手动选择 OpenAI 时保留其原流程，不静默切回 DeepSeek。
- 只有一个原生执行器。当前动作交付执行时异步发起一个候选计划，不让两个 worker 同时操作键鼠。

## 预测与执行

1. 仅保留深度为 1 的候选，不形成不可取消的动作队列。
2. 短移/导航宏必须有可校验的预测距离，误差 1–3m，且受当前动作可达范围约束；未知地形或无 HUD 不预规划。传送的预测坐标只能来自已校验目录项。
3. 下一帧必须关联同 nativeId、连续 seq 和前一动作的完整回执；截图须在动作完成之后。任务、阶段、场景和交互提示重新核对。短移还核对原生发送时长、HUD、地形、姿态及标记方向。
4. 传送返回不代表到达。原生增加两次不使用缓存的小地图 CV 定位；要求新鲜、相互差 ≤10 游戏坐标单位、两者距目录点均 ≤12 单位。定位失败只使候选作废，不凭返回字符串确认到达。
5. 命中后仍通过当前帧动作校验，并由原生执行前再次核对焦点/期限/OCR。原生从当前视觉求几何，模型不能输出自由坐标或脚本。
6. 状态不符、候选尚未完成、过期、格式错误、当前校验拒绝，立即丢弃并重新决策。不会等待慢的预规划，也不会复用投机的 wait/stop 阻塞正常规划。
7. 新任务、父会话取消、退出时清空候选并取消请求。已返回但被丢弃的调用仍计入源帧；被取消而无 usage 的调用记为用量未知，不冒充零成本。复用帧不重复记账。

预测输入明确标为 hypothetical，清除原位置的 OCR/交互目标，不能把传送前的 NPC 或按钮当作传送后事实。当前先预规划一项受控意图，而不是生成并盲执行任意路线脚本。蒙德凯瑟琳示例仍须已知目标、目录锚点及当前位置证据；本改动没有虚构凯瑟琳路线数据。

## 验证

- 相关回归批次 115 项通过；后来补充投机 wait/取消计费测试后，22 项聚焦回归通过（与前一批有重叠，不累加为独立覆盖）。工作区在制小地图相关 39 项通过。
- 整链路模拟：第一次移动尚未结束时下一次规划已启动；第二帧匹配后没有新增前台模型调用；第三帧进入菜单，旧移动计划被拒绝并由交互 worker 重新决策。全过程没有生成解说。
- 真实 API 连通测试：`deepseek-flash`，明确 disabled，输出 14 token，输入 670 token，耗时 1489ms，响应无 reasoning_content；服务没有单列 reasoning token 计数，因此该计数仍记 null。动作 JSON 通过现有校验，但未交付游戏。证据：`runtime/genshin/fast-workers-api-smoke.json`。
- 首次连通测试出现 action 字符串而非对象，未执行；补上明确 JSON 示例后第二次测试通过。不能用一个样本承诺固定响应延迟或格式成功率。
- 用户叫停的 Codex 接管 run `eeab6c9e-edb2-4874-a98d-0e8928079914` 没有提交游戏决策，已结束；native `58844fc3-31ea-4228-8e12-b04b081fffbb` 确认 inputReleased/processStopped=true，视觉空闲。
- 架构改动没有新实机 run。20 分钟评估器前值为 halted/idle、0帧、0移动、0路径，P0未通过；维护无帧不是推进证据。

## 边界

当前仍保留每帧本地视觉/OCR核验；它的延迟可能成为下一瓶颈，尚未证明端到端高频或通关。低命中率时预规划可能额外花 token，源帧记账可用于后续评估。小地图任务方位识别问题仍属于独立工作，不因关闭思考或模型分工而自动解决。
