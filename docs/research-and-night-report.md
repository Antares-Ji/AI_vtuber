# 大脑、情绪、人格与记忆研究实施报告

更新时间：2026-08-17

## 1. 研究结论

### 1.1 情绪不是一个标签

- [OCC 模型的心理建构解释](https://pmc.ncbi.nlm.nih.gov/articles/PMC4243519/)将情绪区分建立在事件、行动与对象的主观意义上，而不是只看表情或生理输出。
- [Component Process Model 的动态架构讨论](https://pmc.ncbi.nlm.nih.gov/articles/PMC2781886/)强调评价、动机、身体反应、表达和主观感受等组件的同步与变化过程。
- [Emotions as Computations](https://pmc.ncbi.nlm.nih.gov/articles/PMC9805532/)总结出目标相关性、目标一致性、确定性、应对潜力和责任归因等核心评价量。
- [Appraisal 与情绪调节综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC2844958/)说明调节策略必须结合事件评价，而不是简单把负面情绪归零。
- [Big Five 与评价过程综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC12758648/)支持“稳定人格影响事件评价，评价再影响短期情绪”的分层方向。
- [Measuring affect dynamics](https://pmc.ncbi.nlm.nih.gov/articles/PMC9918585/)区分平均水平、波动、不稳定性和惯性，支持把情绪建模成时间序列而非单点标签。
- [Can LLM Agents Maintain a Persona in Discourse?](https://aclanthology.org/2025.emnlp-main.1487/)显示人格维持会随模型和对话设置明显变化，因此不能只写一次人设提示词就假设一致性成立。
- [Beyond Static Persona Consistency](https://aclanthology.org/2026.acl-long.1336/)进一步区分僵硬的一致与随情境合理演化的人格连贯性。
- [Generate, Delete and Rewrite](https://aclanthology.org/2020.acl-main.516/)说明一次生成不能可靠保证人格一致，生成后的矛盾检测与窄范围修正应当独立存在。

工程结论：本项目不再用一个 `happy/annoyed` 标签代表全部状态。内部保存 63 个可观察情绪量，按核心、事件评价、离散情感、社会关系、动机和调节分组；外部再压缩成主情绪、台词语气、TTS 参数和 Live2D 表现。

### 1.2 记忆必须有层级、更新与弃答

- [Generative Agents](https://arxiv.org/abs/2304.03442)表明观察、规划和反思共同影响可信行为，缺少任何一项都会降低可信度。
- [MemGPT](https://arxiv.org/abs/2310.08560)把有限上下文管理类比为分层存储，支持工作记忆与外部长期记忆分开。
- [CoALA](https://arxiv.org/abs/2309.02427)提出模块化记忆、结构化行动空间和决策循环。
- [Reflexion](https://arxiv.org/abs/2303.11366)把语言反馈保存在情节记忆中，不需要修改模型权重也能形成可复用经验。
- [LongMemEval](https://arxiv.org/abs/2410.10813)把长期记忆拆为信息抽取、跨会话推理、时间推理、知识更新和弃答五类能力。
- [ES-MemEval](https://arxiv.org/abs/2602.01885)把情绪支持场景进一步拆为抽取、时间推理、冲突检测、弃答和用户建模，说明“记得事实”不等于“理解持续变化的人”。
- [Reflective Memory Management](https://aclanthology.org/2025.acl-long.413/)提出前瞻式多粒度摘要与基于证据的回顾式检索修正，支持把会话提炼与检索反馈分开。
- [SHARE](https://aclanthology.org/2025.acl-long.704/)强调双方共同经历对长期对话延续的重要性，但共同记忆仍需来自真实互动证据。
- [Inside Out / PersonaTree](https://aclanthology.org/2026.acl-long.614/)使用受约束的 ADD、UPDATE、DELETE、NO_OP 操作控制长期画像增长，避免无限追加造成噪声和人格矛盾。
- [LoCoMo](https://aclanthology.org/2024.acl-long.747/)显示长上下文或普通 RAG 仍明显落后于人类，尤其在长期时间与因果关系上。
- [LoCoMo-Plus](https://aclanthology.org/2026.acl-long.1150/)进一步指出隐含目标、状态和价值约束不能只靠字符串匹配评测。
- [MemoryOS](https://aclanthology.org/2025.emnlp-main.1318/)采用短期、中期、长期之间的动态更新和分段组织。
- [Amory](https://aclanthology.org/2026.eacl-long.183/)使用情节叙事、巩固动量与语义记忆形成连贯长期结构。
- [TiMem](https://arxiv.org/abs/2601.02845)使用时间层级树与巩固机制降低检索上下文长度。

工程结论：本项目使用会话临时记忆、经审核事实、关系画像、角色反思、连续经历和行为经验六类信息；生成候选后必须人工确认。检索加入低相关拒绝，避免为了显得熟悉而乱提过去。

### 1.3 人格一致性需要生成后的检查

- [Dialogue NLI](https://aclanthology.org/P19-1363/)把人格矛盾转化为自然语言推理中的蕴含、矛盾与中立判断。
- [Pragmatic Self-Consciousness](https://aclanthology.org/2020.emnlp-main.65/)通过假想听者减少人格与上下文矛盾。
- [Generate, Delete and Rewrite](https://aclanthology.org/2020.acl-main.516/)说明生成、删除矛盾内容、重写比只依赖一次生成更可靠。
- [Offline RL Persona Consistency](https://aclanthology.org/2023.emnlp-main.110/)说明可用离线奖励和惩罚经验提高一致性，但训练成本和数据质量仍要单独评估。

工程结论：稳定人格使用 34 维数值画像和角色包；输出经过独立策略层，检查身份冒充、能力夸大、密钥泄露、版权歌词、排他依赖和长度失控。离线评测失败会进入行为经验库，不进入角色真实经历。

### 1.4 人情味不能依靠依赖操控

- [社会情绪调节模型](https://pmc.ncbi.nlm.nih.gov/articles/PMC5937233/)将帮助他人调节情绪视为双向、分阶段的社会过程；较隐性且被感知为善意的方式通常更有效。
- [个性化情绪调节](https://pmc.ncbi.nlm.nih.gov/articles/PMC5939931/)强调人、情境与策略的交互，没有一种策略适合所有人和情境。
- [Illusions of Intimacy](https://arxiv.org/abs/2505.11649)分析真实社交聊天数据，指出情绪操控、自伤与有毒关系模式的风险。
- [Emotional Support with Conversational AI](https://arxiv.org/abs/2603.22618)指出支持与依赖、确认感受与强化妄想之间存在持续张力。

工程结论：角色可以感谢粉丝、珍惜共同经历、记住经确认的信息，但不能要求排他关系、贬低现实关系或用离开威胁观众。高风险情绪支持仍不能代替专业帮助。

### 1.5 声音与歌唱必须拆成两条管线

- [Beyond Sentence-level Labels](https://aclanthology.org/2026.findings-acl.940/)显示，对话上下文和角色经历能提升情绪语音的自然度，单句情绪标签的信息不足。
- [EmoKnob](https://aclanthology.org/2024.emnlp-main.466/)说明情绪强度需要细粒度控制，而非只切换几个类别。
- [TTS Dynamism 用户研究](https://aclanthology.org/W19-5935/)发现合适的情绪感叹和语音动态能提升社交对话评分，但填充词并非在所有听者视角下都有正收益。
- [DiffSinger](https://arxiv.org/abs/2105.02446/)和 [VISinger 2](https://arxiv.org/abs/2211.02903)都以乐谱、音高和时值为核心条件，证明歌声合成不是把普通 TTS 文本拉长。

工程结论：普通对话继续由 GPT-SoVITS 负责，并支持按情绪选择不同合法参考音频；歌唱保持独立 provider，未来接收 MIDI/乐谱、歌词音素、授权曲目与合法歌声模型。

## 2. 当前架构

```text
角色包（身份/世界书/文化背景）
          ↓
稳定人格（34维，长期秉性）
          ↓
事件评价 → 动态情绪（63维） → 调节策略
          ↓                         ↓
分层记忆 → 认知规划/能力边界 → 回复草稿
          ↓                         ↓
相关行为经验检索             输出策略检查
                                    ↓
                       台词 / TTS / Live2D 动作
```

角色包可以替换；情绪、人格、记忆、规划、策略和表现引擎不依赖洛天依世界书。洛天依相关内容位于 `src/character/luotianyi.js`，通用契约位于 `src/character/core-persona.js`。

65. 低质量隔离是可逆的：在工作台把内容提炼为稳定记忆后即可重新参与检索，系统不会静默删除历史。

70. 导演工作台新增最近训练反馈明细，可回看输入、回答、情绪和人工修正备注；原文经过 HTML 转义且仍只保存在本机。
71. 情绪 schema 新增结构门禁：63 个维度必须唯一且每项必须有中文显示名，防止未来扩展时出现重名或调试面板裸露英文键。
72. 动态角色名夸奖归入通用 praise 事件族，确保温暖与感恩人格权重会真实调节反应幅度，并增加高低人格对照测试。
73. 隐私删除审计修复关系表遗漏：忘记用户现在会清除长期记忆、会话、事件、候选、审计归属、用户档案、关系参数及训练员反馈，并增加数据库级断言。
74. 统一长期记忆敏感信息策略：工作台编辑入口不再能绕过手机号、地址、邮箱、证件和账户信息检测，拒绝后保留原记忆不变。

## 5. 仍然存在的真实差距

- 63 个维度是可解释的工程状态，不等同于真实意识或完整人脑。
- 当前中文规则只能识别有限事件；后续需要小模型或 LLM 结构化评价器并配人工标注集。
- 长期记忆尚未接向量嵌入；当前字符、概念和关系检索适合 MVP，但大规模数据后需要混合向量检索与时间推理。
- 人格一致性策略目前以规则为主，未来可加入中文 NLI critic，但必须评估延迟。
- 歌唱目前只有素材检查与授权门禁；即使素材齐全，也要等渲染、播放和统一音频队列真正实现后才可变为 ready。
- GPT-SoVITS 是语音 TTS，不承担高质量歌声合成主职责。
- “接近 Neuro-sama”还需要长期直播数据、持续人工评测、稳定低延迟语音、真实 B 站接入、游戏视觉和长期运行经验。
