# 项目键鼠程序：杀戮尖塔 2 拖拽验证

用户要求由项目本身实现键鼠操作。最终成功试次由 `scripts/game-input-run.py` 执行，复用 `scripts/sts2/native_input.py` 的 Win32 SendInput；截图和录像由本地 mss/OpenCV 生成。此试次没有调用 Computer Use 桌面控制、游戏模组动作接口或游戏内存。

## 入口

```powershell
# 仅激活指定游戏并保存当前画面，不出牌。
.\runtime\vlm-env\Scripts\python.exe scripts/game-input-run.py --exe SlayTheSpire2.exe

# 真实拖拽：仅用于已确认手牌位置和目标仍与本次画面一致的情况。
.\runtime\vlm-env\Scripts\python.exe scripts/game-input-run.py --exe SlayTheSpire2.exe --actions scripts/game-input-trials/sts2-strike-drag.json --execute
```

动作配置表达 move → 等待悬停展开 → left down → 按住移动 → 目标上短暂停留 → left up。移动采用最小加加速度曲线，当前拖动段 1.3 秒，松手前停留 0.6 秒，均可在 JSON 中调整。坐标相对客户区，不包括标题栏。

窗口激活加入临时 AttachThreadInput 后备路径，激活后立即分离输入线程。只在批次开始激活；执行中失焦仍停止，不持续抢夺用户焦点。F8、停止文件、异常均触发释放。普通 CLI 与管理员游戏权限不匹配时仍拒绝。
