用户更正：使用 BGI 自带视觉；DeepSeek 独立寻路与交互、关闭思考、少输出；持续走较长距离，在本地高频修正。当前目标仍是每日委托「紧急修理」，纯游戏 OBS 录像最终输出 20 倍速。

## 已接入

- 剧情帧由同一 BGI 截图上的 `Bv.WhichGameUi`、关闭按钮模板、运动状态模板及原生 OCR 提供。`story-runtime` 不再调用 17646 的 Qwen 推理，也不以其健康状态作为续段条件。旧独立诊断 observe 工具尚保留，但此剧情循环不使用。
- 两路 DeepSeek Flash API worker：移动输出上限 128 token，交互 384；两者请求显式 `thinking: disabled`，解说为空。输入含短交接及实际回执；前台输入只有一个执行器。
- `travel_quest`：原生小地图投影，首段 25m 核验方向，后续最多 180m/60秒；BGI PathExecutor 内部持续 CV 修正，外部原生 OCR 监控交互/菜单/阶段/距离并取消、等待退出。仍不把返回当到达。
- `navigate`：连续持键 0.4–8秒，期间本地 OCR、BGI 运动状态和小地图位置反馈；不会每400ms松键。距离反增/卡住会返回。实机本地检查约400ms一次，不能把200ms等待宣称成固定5Hz。
- `seek_quest`：有5–300m任务距离但缺图标时，原生距离反馈尝试不同方向，保留下降方向连续移动，最多60秒/8段；这是局部反馈，不是全局障碍地图。
- `search_area`：当前OCR确认已到搜索区后，原生双次CV确定搜索起点，在周边18m内按6m间距巡查。由PathExecutor走坐标路径，途中OCR发现交互/阶段变化即取消并等待路径退出；同一原生会话保留巡查点进度。
- DeepSeek明确选择离开一个交互物后，同阶段导航可经过该精确同名提示；其他F提示和菜单仍停止。BGI确认Climb时提供X脱离攀爬，并在执行前再次识别。
- 普通对话 SPACE 意图最多连续推进20次/30秒，有回复选项、场景变化或字幕停滞即返回模型。离开无关NPC提示有独立的有界意图。
- 单步预规划仍需动作回执和新鲜状态匹配；不是并发发送键鼠。启动报告原生能力；没有投影 API 时不向模型提供 travel_quest。
