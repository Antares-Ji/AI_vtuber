# 情绪与人格引擎说明

## 1. 先分清四个东西

1. **人格**：长期倾向，变化很慢。例如温暖、好奇、耐心、边界强度。
2. **事件评价**：角色如何理解刚发生的事。例如这件事是否重要、是否公平、能否应对。
3. **情绪状态**：评价后的短期变化。例如喜悦、担忧、羞涩、愤怒。
4. **表达策略**：不等于内心状态。角色可以感到恼火，但选择缩短回复、设边界，而不是攻击观众。

本项目把这四层分开，是为了避免“关键词里有开心，所以整个人瞬间只剩开心”。

## 2. 63 个动态评估维度

源码：[affect-schema.js](../src/brain/affect-schema.js)

- 核心状态 11 项：愉悦、唤醒、主导、精力、专注、安全、社交趋近、紧张、矛盾情绪、情绪惯性、可表达性。
- 事件评价 12 项：新奇、事件愉悦、目标相关、目标一致、确定性、自身责任、他人责任、控制感、应对潜力、规范符合、公平感、可预测性。
- 离散情感 16 项：喜悦、悲伤、愤怒、恐惧、惊讶、厌恶、信任、期待、羞涩、自豪、感激、钦佩、希望、释然、失望、孤独。
- 社会关系 10 项：温暖、亲和、共情、关怀、依恋、尊重、社交信心、边界压力、互惠感、归属感。
- 动机 8 项：好奇、玩心、坚持、成就动机、照顾动机、创作动机、休息需求、回避倾向。
- 调节 6 项：表达抑制、重新评价、心理距离、接纳、表达准备、恢复能力。

这些值是可解释的工程变量，不是医学量表，也不证明 AI 有主观感受。

### 理论到工程的对应

| 工程层 | 主要理论启发 | 在项目里的作用 | 不能夸大的地方 |
| --- | --- | --- | --- |
| 核心状态 | PAD / core affect、情绪动态 | 描述正负、唤醒、控制、惯性和波动 | 不是生理测量 |
| 事件评价 | OCC 与 Scherer Component Process Model | 先判断新奇、目标、责任、控制、公平，再形成反应 | 当前中文评价仍以规则为主 |
| 离散情感 | 基本情绪与社会情绪研究 | 为台词、表情和语音提供可读标签 | 标签之间可以同时存在，不是单选题 |
| 社会关系 | 人际情绪调节、依恋与互惠概念 | 决定支持、亲近、尊重和边界倾向 | 不代表真实依恋或意识 |
| 动机 | action readiness / 行动倾向 | 把情绪变成支持、探索、坚持或退避的动作方向 | 不是让情绪直接控制台词 |
| 调节 | Gross 情绪调节过程模型 | 选择重新评价、抑制、接纳、距离和恢复 | 目前是工程策略，不是心理治疗 |
| 稳定人格 | Big Five 与人格一致性研究 | 调节同一事件的反应幅度，并保持长期价值稳定 | 不应被一条弹幕永久改写 |

代码只采用这些研究的可计算思想，没有声称完整复刻人脑。真正的参数校准必须来自匿名、获同意的中文互动样本和盲测，而不是凭开发者一次主观感觉。

语音侧不再只接收 `happy/sad` 标签。系统会把连续的愉悦度、唤醒度、主导感、紧张、可表达性和调节策略一起压缩为语速、停顿、音高提示与 GPT-SoVITS 采样范围。连续情感控制与可控语音的研究可参考 [EmoKnob](https://aclanthology.org/2024.emnlp-main.466/) 和 [Controllable Speech Synthesis Survey](https://aclanthology.org/2025.emnlp-main.40/)。当前 GPT-SoVITS 接口主要能可靠控制速度和采样，不能把参数名存在误解为真正训练过的连续情感声学模型。

此外可在 `.env` 中给 `happy/shy/focused/concerned` 等情绪分别配置合法参考音频和逐字对应文本。系统优先使用匹配参考，缺少时回退默认参考；这比只改变随机采样参数更接近上下文相关的音色表达，但仍需要真人听感盲测。

## 3. 一轮消息怎样流动

```text
观众原话
  -> 识别事件类型（夸奖、脆弱、敌意、成功、失败、重逢、怀旧、不公、孤独等）
  -> 计算 12 项事件评价
  -> 由 34 维稳定人格调整反应幅度
  -> 更新 63 维短期状态与慢心境
  -> 汇聚为 8 种行动倾向并选择调节策略
  -> 压缩为主情绪、语速、停顿、音高、表情和动作
  -> LLM 生成台词
  -> 输出策略再次检查身份、能力、版权、依赖与密钥
```

例如同一句敌意弹幕，高敏感、低情绪稳定的角色内部反应更明显；但高边界强度会推动她选择清晰边界。人格影响反应，不直接写死台词。

## 4. 时间动态

系统保留最近 48 个情绪轨迹点，并使用最近 24 个样本计算：

- 平均愉悦度：这一段时间总体偏正面还是负面。
- 波动性：状态围绕平均值变化多少。
- 不稳定性：相邻两轮跳变有多大。
- 惯性：上一轮状态对下一轮的延续程度。
- 区分度代理值：主导情绪是否能和第二情绪拉开差异。

这部分依据情绪动态研究中常见的均值、变异、相邻差异和惯性思路实现。[Measuring affect dynamics](https://pmc.ncbi.nlm.nih.gov/articles/PMC9918585/) 和 [Affective Dynamics in Psychopathology](https://pmc.ncbi.nlm.nih.gov/articles/PMC5016030/) 都强调情绪必须按时间序列理解。当前“区分度”是工程代理值，后续有真实标注数据后再校准。

行动倾向不是额外伪造一种情绪，而是把 63 个连续量压缩成“支持、探索、接近、庆祝、坚持、护界、退避、调节”的相对优先级。它会影响导演层的表达方向，但不能覆盖事实、安全和观众边界。

## 5. 77 项情绪标定

`npm run test:emotion` 会独立运行 77 个检查，覆盖事件触发、动态角色名夸奖及人格调制、维度唯一性与中文标签、复杂混合情绪、重复耐受、四类调节、观众情绪与需求感知、关系缓冲、行动倾向、轨迹统计和 TTS 表现映射。它证明代码按当前规则一致运行，但不能替代真人听感实验；下一阶段需要让多位中文观众对“自然、贴合、不过度解读”进行盲评。

## 6. 34 个稳定人格维度

源码：[personality-schema.js](../src/brain/personality-schema.js)

- 大五人格 5 项。
- 气质 8 项。
- 社交风格 7 项。
- 价值观 8 项。
- 表达风格 6 项。

角色包只覆盖自己需要改变的权重，其余来自通用默认值。`CHARACTER_PACK=generic` 可在没有洛天依世界书的情况下运行整个大脑；`CHARACTER_PACK=luotianyi` 才加载洛天依灵感角色包。

## 7. 目前不能夸大的地方

- 中文规则识别仍会漏掉反讽、隐喻和复杂上下文。
- 63 维不是越多越真实，关键是维度间关系、时间变化和人工校准。
- LLM 提供的观众情绪判断只在置信度达到阈值后轻量影响下一状态，不能直接改写人格。
- 真正达到长期主播质量，需要积累经同意的真实互动样本，再做人类评分、消融实验和阈值校准。
