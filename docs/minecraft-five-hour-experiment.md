## 哪部分由模型做

`src/minecraft/survival-planner.js` 将观察和最近执行结果交给本地千问，模型输出一个受限 JSON 技能。没有按进度写死的规则代替模型选择采集、合成或挖矿。`src/minecraft/autonomy-loop.js` 调用模型、记录延迟、检查状态是否过期、提交带 taskId 的技能并等待实际结果。

`scripts/minecraft-session.js` 保持游戏连接，串行执行技能。`src/minecraft/survival-skills.js` 负责寻路、点击、挖掘等低层动作和世界／背包验证。`src/minecraft/reactive-agent.js` 是即时安全层：200ms 检查及血量事件触发、打断、避险；这部分反射能力不能计为模型学会保命。

训练失败、任务失败、停止循环都不自动退出游戏。超时或取消使用关联任务编号拦截旧结果；底层 API 尚未结束时不接受另一技能。窗口截止停止自主循环及当前技能，保留连接。
