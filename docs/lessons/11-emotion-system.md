# 第 11 课：情绪系统

本课目标：理解情绪为什么从简单文字升级成分数。

## 先讲理论

真实一点的情绪不是“开心/不开心”开关，而是会有强度，也会慢慢变淡。

## 对应源码

- `src/brain/emotion.js`

里面有：

- `EMOTIONS`：情绪名称。
- `EMOTION_KEYWORDS`：关键词规则。
- `scores`：每种情绪的分数。
- `decayEmotion()`：情绪衰减。

## 小白版解释

```text
弹幕夸主播 -> shy 分数上升
一段时间没有继续触发 -> 分数慢慢下降
最高分的情绪 -> 当前表现出来的情绪
```

## 小练习

在 `EMOTION_KEYWORDS` 里加一个关键词规则，比如“困了”触发 `neutral` 或 `shy`。
