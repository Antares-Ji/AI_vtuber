# 第 2 课：`index.html` 页面结构

本课目标：知道网页上的按钮、输入框、角色、字幕在 HTML 里对应哪里。

## 两个大区域

```html
<main class="app">
  <section class="stage">...</section>
  <aside class="control">...</aside>
</main>
```

人话：

```text
stage = 左边主播舞台
control = 右边控制台
```

## 重要元素

- `#avatar`：角色。
- `#mouth`：嘴巴。
- `#subtitle`：字幕。
- `#danmakuForm`：弹幕表单。
- `#queue`：弹幕队列。
- `#memory`：短期记忆列表。

一句话记忆：

```text
HTML 只是先把页面上的零件摆好。
```
