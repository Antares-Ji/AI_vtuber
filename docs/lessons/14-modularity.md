# 第 14 课：模块化

本课目标：理解为什么工程要拆成很多小文件。

## 先讲理论

模块化就是：

```text
一个文件只负责一类事情。
```

## 当前模块

- `persona.js`：人设。
- `emotion.js`：情绪。
- `memory.js`：记忆。
- `llm.js`：外部模型。
- `reply.js`：回复组织。
- `provider.js`：TTS 状态入口。

## 小白版解释

```text
模块化像分工：
有人管人设，有人管情绪，有人管记忆。
改一个模块时，不容易把全部东西弄坏。
```

## 小练习

打开 `src/brain.js`，只看函数名，不看细节，尝试说出每个函数大概负责什么。
