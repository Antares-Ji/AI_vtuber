# 更新记录

- 新增默认关闭的本地导演任务 API、客户端主线程适配及无游戏 HTTP 测试；协议见 docs/DIRECTOR_API.md。

## 0.4.0-alpha.1 — 2026-10-30

- 长期方向调整为以 Minecraft 为首个环境的开放 harness，保留来源说明及现有执行约束。
- 新增实例级 SkillRegistry、具名版本与可信 SkillProvider 服务发现；内置技能迁移到同一注册入口，旧技能短名仍兼容。
- PlayerTasks 的静态安装与调用改为实例，复合技能通过传入的注册表调用具名子技能；Java 宿主迁移说明见 docs/EXTENSIONS.md。
- 现有 player-control.json 支持 schema_version、执行预算与技能选择；启动前严格校验，F8 保存保留高级字段，运行中的配置保持固定；任务页只更新存档目标，不覆盖用户在文件中编辑的模型设置。
- 任务记录增加配置哈希和技能版本，不写入原始 profile、提示词或密钥。
- 独立 collect-return 示例展示公开接口组合、服务发现、取消及证据核验；CI 和发布检查纳入示例测试。
- 扩展 Java 库尚非加载器可安装模组；游戏内安装、真实模型和客户端行为仍待验证。

- Alpha API 与配置仍可能调整；实际验证范围见 docs/VALIDATION.md。

## 0.2.0 — 2026-10-28

- F8 改为任务控制台：以本存档目标、执行结果和模型耗时为中心，连接与提示词配置移到二级界面。
- 新增独立的 `dev.mcplayeragent.mission` 模块及 Minecraft 适配器；实际模型响应、计划、技能、危险中断和服务器动作回执进入任务时间线。
- 每次接管生成新的运行 UUID，异步写入存档的 `mcplayeragent/runs/`；区分已验收、未验收和已中断。
- 增加 5 项任务记录行为测试；累计 74 项核心单元测试，两个加载器各 3 项拾取集成测试通过。
- 对照原始下载快照修正来源清单：57 个提取文件不在该快照中，4 个来源文件存在；保留实际来源与许可证。
- 建立独立项目定位及后续开发边界。

客户端任务控制台的视觉和交互、长时间自动生存仍待实机测试。服务器 GameTest 不覆盖这些行为。
