# 安全说明

## 支持范围

当前维护线为 `0.3.0-alpha`。这是实验性项目，没有安全审计认证或修复时限承诺；早期 `0.1` / `0.2` 不作为当前维护线。

## 报告漏洞

不要在公开 Issue 中提交 API Key、私有服务器地址、完整个人存档或可直接利用的漏洞细节。

仓库上传 GitHub 后，若 Security → Advisories 中提供 **Report a vulnerability**，请使用私密报告，并附上受影响版本、最小复现、影响范围与脱敏证据。该入口取决于仓库所有者是否启用私密漏洞报告，本文件不代表已启用。

若没有私密入口，可开一个不含漏洞细节的 Issue，请维护者提供私密渠道；不要先公开敏感内容。

## 运行边界

- API Key 存在游戏实例的 `config/mcplayeragent/client/keys/`，是本机明文文件；不要分享该目录。
- 目标、环境观察及对话配置会发送给你选择的模型服务。自行确认该服务的隐私设置和费用。
- 运行记录包含目标、动作和结果；分享前检查个人信息。记录器不接收密钥或私有推理字段，不代表任意外部日志都已脱敏。
- 模组会操作真实玩家并修改世界；先备份测试存档。F9 或物理输入用于停止接管。
- 当前只支持单人世界和本机局域网房主；尚未验证不可信多人环境或恶意模型输出下的完整防护。

若密钥已泄露，先在模型服务端撤销或轮换，再清理公开文件及 Git 历史；仅从最新文件中删除密钥不足以撤销它。
